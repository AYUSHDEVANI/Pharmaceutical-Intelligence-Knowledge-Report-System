# PIKRS AI Insight Engine

The AI Insight Engine serves as the core reasoning layer of the PIKRS platform. It consumes the standardized `DrugProfile` generated by the backend Orchestrator and transforms the raw JSON into a highly readable, strictly structured `DrugIntelligenceReport`.

## Configuration

This module utilizes **Groq** (or optionally OpenAI) for blazing-fast inference.

To prevent hard-coding API keys, you **must set up your environment** before running the pipeline.

### Step-by-Step Setup:
1. **Copy the example environment file:**
   Navigate into the AI Engine folder and copy the template:
   ```bash
   cd a:\pharma\orchestrator\ai_engine
   cp .env.example .env
   ```

2. **Add your API Credentials:**
   Open the newly created `.env` file and insert your API key:
   ```env
   GROQ_API_KEY=gsk_your_actual_key_here
   GROQ_MODEL=llama-3.1-70b-versatile
   LLM_TIMEOUT=30
   ```
   *(If you are intending to use the OpenAI fallback, add `OPENAI_API_KEY` instead).*

3. **Restart the Application:**
   If running via Docker, or if your local terminal session was previously active, reboot the orchestrator process so the Pydantic configurations can capture the new variables.
